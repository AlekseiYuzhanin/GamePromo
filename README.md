Суть: Микросервис, который управляет выдачей случайных наград (скины, бонусы, фриспины). 
Запрос от игры → сервис рассчитывает дроп по весам → применяет редкие флаги (комбо, гаранты, х2).

Микросервисы:

API Gateway (Auth, rate-limit) — на echo или fiber.

User Progress Svc — хранит историю открытий пользователя.

Random Generator Svc — ядро на math/rand/v2 или crypto/rand + распределение.

Reward Dispatcher — асинхронно начисляет награду через брокер (NATS/Kafka).

Analytics Svc — собирает метрики (Win rate, RTP, срабатывание гарантов).

Фишки Go: sync.Pool для экономии памяти, atomic для счётчиков, context.WithTimeout для RPC.

Стек протоколов: gRPC (внутри), NATS (ивенты), Redis (лимиты).

Тестовое окружение будет в докер-компоузе, потом переношу в кубер
